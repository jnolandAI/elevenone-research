What actually changed, so you can hold me to it. No 1px borders. No tracked uppercase labels outside of numerals. No boxed tables with visible cell rules. No flat grey fills. Corner radius on everything. Elevation and gradient doing the separation that hairlines were doing before.

What did not change. Neutral grey #EAEAE8, brass #C9A227 with #6E5A1E for small text, colour only ever encoding, one accent per surface, and every number on this page still coming from the same 2,186 SEC registrants.

Still to carry over. The WebGL hero currently uses the old register in its overlay, with mono uppercase everywhere and a bordered readout. It needs this same pass, and the object itself would take a gradient environment and a brass bloom on the marked ridge.
