Achromatic system, one accent

No brand palette. The interface is a single grey scale, the object carries all of its material from light rather than hue, and exactly one accent exists. The only open decision is which accent, and how warm the grey underneath it should be.

Every chart is the same 2,186 SEC registrants, CY2024. The greyscale is held identical across all six so the accent is the only variable.

Rule applied throughout: the accent marks the single most important value on a surface and nothing else. It never carries confidence, never fills a button, never appears twice where once will do.

Fixed interface scale — shared by every option below
Object value ramp — what the rendered surface is coloured with

How warm should the grey be?

A separate decision from the accent, and a real one. Cream and paper tones are out by your own constraint, but there is meaningful range between a blue-leaning grey and a warm-leaning one before anything reads as paper. Shown with gold, since that is where you are leaning.
