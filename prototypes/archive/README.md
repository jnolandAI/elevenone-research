# archive

Colour-system prototypes, superseded by the eleven-gradient set in
`../../design-canvas/`. Kept as the record of what was tried; not linked from
`docs/`, not published, and not to be revived without deciding first that the
set was wrong.

Every one of these proposes colour as an ACCENT: a hue applied to interface
furniture, a brass rule, a coloured card header. The set replaced that outright.
Colour now arrives only as a gradient, only as a field or an ordered encoding,
and furniture is greyscale on every page.
