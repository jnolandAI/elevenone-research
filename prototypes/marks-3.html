You were right to stop on this. S3 as drawn is a linear ramp, and a ramp is a decoration: it runs from light to dark and asserts nothing. Every version below keeps exactly what you liked, an unbounded field with no container, and changes only what drives the density. Each one is judged on two things: whether the meaning is true, and whether a stranger would ever get it unprompted.

On meaning that nobody decodes. A mark does not have to be legible as an idea to a stranger. It has to be true, so that the story holds when you tell it, and it has to be distinctive, so that it is yours.
